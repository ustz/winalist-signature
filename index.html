Install the signature

Spark (Mac, iPhone, Android)

  1. Open Settings, then Signatures.
  2. Create a signature with +.
  3. Paste (⌘V) into the field, then assign it to your Winalist account.

Gmail (browser)

  1. Gear icon, then “See all settings”.
  2. General tab, Signature section: “Create new”.
  3. Paste, then select it for new emails and replies.
  4. Click “Save changes” at the bottom of the page.

Apple Mail

  1. Mail, then Settings, then Signatures.
  2. Pick your account and add a signature with +.
  3. Untick “Always match my default message font”.
  4. Paste into the right-hand field.

Outlook

  1. Settings, then Accounts (or Mail), then Signatures.
  2. New signature, paste.
  3. Set it as default for new messages and replies, then save.

No phone number in the signature: every host request goes to host@winalist.com. If pasting drops the images, use “Copy HTML code” when your email app accepts HTML.
